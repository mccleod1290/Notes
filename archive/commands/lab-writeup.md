# /lab-writeup

Write a CTF/HTB/lab writeup with **writeup-writer**:

- skill `lab-writeup` (Medium-style steps + Beyond Root)
- skill `simple-english` **1× pragmatic only**
- **no** frugal-eval

## Usage

```text
/lab-writeup
# or
spawn writeup-writer with topic + path + mode blog|obsidian + land
```

Default mode: blog (screenshots or TODO_SCREENSHOT).
Land: notes | llm-wiki | github.io | pwnjournal per user.
