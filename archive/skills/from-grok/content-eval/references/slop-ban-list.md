# slop ban list (pass 1)

delete or rewrite on sight. not exhaustive — kill the *pattern*.

## openers / throat-clearing

- in this article / in this guide / in this comprehensive overview
- let's dive in / let's explore / without further ado
- it is important to note / it is worth noting / needless to say
- in today's fast-paced / in the ever-evolving landscape
- as we all know / as mentioned earlier (when nothing was)

## AI glue words

- delve / dive deep / unpack
- leverage / utilize (prefer use)
- robust / seamless / holistic / comprehensive / cutting-edge
- empower / unlock / harness / elevate
- game-changer / silver bullet / secret sauce
- tapestry / landscape / journey / realm / space (as vague noun)
- foster / streamline / facilitate (when empty)
- pivotal / crucial / vital (stacking intensifiers)
- navigate / landscape of X

## structure theater

- "key takeaways" that restate the body
- numbered lists of synonyms
- bold every other word
- emoji section headers
- "in conclusion" essays after short notes
- FAQ that invents questions nobody asked

## operator-doc anti-patterns

- "configure appropriately" with no values
- "various techniques exist" with no names
- "depending on the environment" with no branches
- theory block with zero do-this next step
- walkthrough tone when the user asked for first principles

## keep instead

- name the primitive
- because X → do Y
- exact header / flag / path when known
- one concrete example
- failure: if Z, then try W
