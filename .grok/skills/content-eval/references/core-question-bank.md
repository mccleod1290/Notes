# core question bank (pass 3)

pick 3–7 that fit the draft. answer in-body or mark `gap`.

## any teaching note

1. what is the one-sentence definition?
2. what problem does this solve for the reader right now?
3. what is the smallest unit to reason about?
4. what must they already know?
5. what will they do differently after reading?
6. what fails first in the real world?

## operator / pentest batch

1. when do I run this (trigger signals)?
2. what is the exact next command / request?
3. what does success look like?
4. what does failure look like and what do I try next?
5. what is the trust boundary / sink?
6. what should I not do (noise, damage, out of scope)?

## checklist

1. is each item a decision or action (not a slogan)?
2. is order chronological or priority-ranked?
3. which items are skippable and when?
4. what evidence closes each item?

## concept / theory

1. mechanism: input → transform → output?
2. high-level map: where does this sit?
3. common misconception?
4. minimal example that proves the idea?

## comparison (A vs B)

1. same goal or different goals?
2. when prefer A / when prefer B?
3. what false equivalence should be avoided?
